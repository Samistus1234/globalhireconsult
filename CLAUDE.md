# Claude Code — cross-assistant handoff

Read and follow `AGENTS.md` and `AI_HANDOFF.md` in addition to other relevant repository instructions.
At the start of a session, verify git status, relevant code and the recorded handoff.
At the end of substantive work or when switching assistants, update `AI_HANDOFF.md` on your working branch with what changed, what was tested, what is uncommitted, and the exact next step; push only if authorized.
Do not store secrets, private client information or raw conversations.
